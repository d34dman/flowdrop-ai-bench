# About Drupal

Drupal is a free, open-source content management system written in PHP and released under the GNU General Public License. It powers everything from personal blogs to the public websites of governments, universities and media groups, and it has been developed in the open by a volunteer community since 2001.

## What makes it different

Most content management systems start from the page. Drupal starts from the content model. Editors describe the kinds of content a site holds, the fields each kind carries, and the relationships between them, and the system builds the forms, listings and APIs from that description. A recipe site can define a *Recipe* with ingredients, cooking time and a reference to a *Chef* without writing code, then expose the same data to a mobile app through JSON:API.

This is the reason Drupal is often chosen over lighter tools such as ████ when a project has many content types, many editors and many outputs. It is also the reason it has a reputation for a steeper start: the flexibility is there from the first minute, and it asks to be used.

## Built on shared foundations

Since version 8, Drupal has been built on components from the Symfony framework, uses Twig for templating and Composer for dependency management. Sites run on MySQL, PostgreSQL or SQLite and on any web server that runs PHP, most commonly Apache or Nginx on Linux. Nothing in the stack is proprietary, and nothing in it is specific to Drupal.

## The community

Drupal is maintained by thousands of contributors coordinated through drupal.org and a GitLab instance where every module, theme and core change is reviewed in public. Contribution is credited to individuals and to the organisations that sponsor their time, which is how a large part of the professional ecosystem funds the work. Regional camps and two DrupalCon conferences a year bring the community together in person.

## Where it fits

Drupal is a good fit when structured content, multilingual publishing, fine-grained permissions or long-term maintainability matter more than getting a first page online in an afternoon. For a five-page brochure site, a hosted product like ████ will be faster to launch. For a site that will still be growing in ten years, the content model is the thing to get right, and that is what Drupal is built around.
