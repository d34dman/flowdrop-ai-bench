## Reading the cost table

- **B3 on Haiku is the cheapest correct run on the small and medium pages**, at $0.025 and
  $0.014. v1 gave both to B3 on Sonnet 5, because v1 penalised Haiku's 69 % retention for
  dropping IBM's header. The medium page B3 Haiku run scores 1.0 on every axis.
- **On the large page the cheapest correct run is B8 on Haiku, $0.15**, two calls. B3 on
  Haiku truncates there (fidelity 0.08); B3 on Sonnet 5 is correct at $0.57. The URL-shaped
  tool is what lets the cheapest model finish the biggest page.
- **Opus 5 costs $0.59–$2.48 per correct run and never fails silently.** Sonnet 5 on B3
  costs $0.23 per correct run with the same record on that variant. The premium buys
  reliability on the agentic variants (B4, B5, B6: 3 of 3 correct each), not on B3.
- **B8 Opus at $1.05 per correct run is the gate, not the model.** Three of its six
  launches paused on B8's `http_request` confirmation gate and cost $0.008 each; the medium
  completion, with the gate waived, fetched the page twice and put 97,768 input tokens on a
  cell Sonnet 5 does for $0.06.
- **B9 costs 2–4× B8 on the same model** for one more correct cell on Sonnet 4.6 and none on
  Sonnet 5 or Opus. Its three loud failures were a FlowDrop bug, fixed the same day.
- **Sonnet 4.6 is the expensive way to be wrong.** $2.18 and $2.26 per correct run on B4 and
  B5: one correct draw out of three and two out of four, with the two reasoning-in-document
  failures and the large-page truncation on its ledger.

## Caveats

n = 1 for most cells, so "cost per correct run" is one draw's cost divided by one or zero.
The table is honest about that in the parentheses. Wall clock on the earliest rows was not
measured and shows as `—`.
